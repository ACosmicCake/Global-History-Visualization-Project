# Attribution sample, 2026-11-03

50 live records picked at random with a fixed seed (20261103), each run through `node atlas/tools/verify.mjs`, which looks for the dates and figures a record credits to a page on that page. No paid model was used.

| Result | Values |
| --- | --- |
| Confirmed on the cited page | 125 |
| Not found | 2 |
| Page unreachable, so not checked | 6 |

Both misses are on `0476-fall-of-the-western-roman-empire`, against Jordanes's *Getica*. The page writes the 709 out in words ("seven hundred and ninth year"), so that miss is a false alarm from the tool's number matching. The 522 appears to be the same case, but its wording wasn't confirmed.

**What this does not show.** The tool checks dates and numbers only. It doesn't test whether a summary's claims are supported, whether the sources are good, or whether a record is true. Recent line-by-line reviews of cheap-model drafts did remove unsupported clauses, so this is not a measured error rate for the records' prose. That needs a reader, human or model, and hasn't been done.
